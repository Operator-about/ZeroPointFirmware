# **ZeroPointFirmware - прошивки для ядра ZeroPiont**
**Предупреждение!** Данные прошивки используются **только** для ядра ОС **ZeroPoint**

# **Доступные прошивки:**
Для **Raspberry Pi4** \
**Планируется так же сделать для QEMU на плату virt с Cortex-A72**

**Что настраивает прошивка:** \
**UARTPL011** \
Пока только **GICv2** \
**GPIO** - **!только для Raspberry Pi4!**

# **Техническая справка:**
Прошивка загружается по адресу: **0x00000000** \
Работает в **EL3** с переходом сразу на **EL1h NS** по окончании работы \
**SP стек выделяется для EL3**

# **Детали работоспособности для устройств:**
Чтобы настроить UART и GIC в Pi4 с помощью данной прошивки, нужно в файле *config.txt* указать следующие: 
```
enable_uart=1
enable_gic=1
droverlay=disable-bt
init_uart_clock=48000000
init_uart_baud=115200
```
